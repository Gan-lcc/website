
# REDLINE MOTORS

## О проекте

REDLINE MOTORS — концептуальный многостраничный сайт автомобильной тематики.

Проект посвящён презентации автомобилей, знакомству с автомобильным брендом и демонстрации каталога моделей.

## Структура проекта

- index.html — главная страница
- models.html — каталог автомобилей
- about.html — информация о компании
- style.css — таблица стилей
- README.md — описание проекта

## Функциональность

- Навигация между страницами
- Каталог автомобилей
- Фильтрация автомобилей по категориям
- Адаптивный дизайн
- Единая система оформления
- Информационные блоки о компании

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
